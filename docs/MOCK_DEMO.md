# Mock 운행 기반 시연 · 0.6 MVP

운행·경로 좌표·차량 설정·기준 단가는 예시입니다. 지도 배경은 OpenFreeMap의 실제 도로/지명입니다. 실제 차량, 순정 내비 또는 실시간 평균 가격을 조회한 결과가 아닙니다.

## 키보드 없는 기본 흐름

1. 초안이 없으면 홈에서 **운행 고르기**를 누릅니다. 기존 초안이 있으면 **이어서 하기**로 하던 단계로 돌아가거나, **새 정산**을 눌러 초안 대체를 확인합니다.
2. 운행 선택에서 11월 1일과 2일의 **이날 모두 선택**을 누릅니다. 여러 날짜를 골라도 자동으로 다음 화면으로 넘어가지 않습니다.
3. 서울 → 춘천 98km / 춘천 → 속초 105km / 속초 시내 24km / 속초 → 서울 188km, **4개 / 415km**를 확인합니다.
4. 우측 실제 도로 지도 위에 겹친 예시 경로에서 선택한 구간을 확인합니다. 좁은 창에서는 **지도로 보기**를 누릅니다. 개별 카드를 해제하면 해당 거리와 비용이 즉시 빠집니다.
5. **운행 4개로 정산하기**를 누릅니다. 기본 연비 **12.5km/L**, 예시 단가 **1,700원/L**, 예상 연료비 **56,440원**을 확인합니다.
6. 기본 인원은 **운전자 포함 4명**입니다. 이름 입력 없이 **결과 보기**를 누릅니다.
7. **한 사람당 14,110원**과 예상 총액 **56,440원**을 확인합니다.
8. **휴대폰으로 요약 받기**로 텍스트 QR을 표시합니다. 휴대폰 카메라로 읽고, 인식하지 않으면 텍스트 QR을 지원하는 스캐너를 사용합니다.

| --- | --- | --- |
| 3명 | 18,814 / 18,813 / 18,813원 | 56,440원 |

## 선택 기능

- **기준 변경**: 휘발유·경유·LPG·전기 예시 설정, 연비·전비, 직접 단가 입력. 예시 전기 설정 5km/kWh / 300원/kWh에서는 415km 비용이 **24,900원**입니다.
- 폼에서 연비를 0 또는 공란으로 바꾸면 적용할 수 없습니다. 취소하면 원래 기준을 유지합니다.
- **통행료·주차비도 있나요?**: 펼쳐서 비용을 추가·수정·삭제합니다. 전체 또는 일부 참여자를 지정할 수 있습니다. 기본 시나리오에서는 건너뜁니다.
- 이름은 **이름 입력하기 (선택)**에서 바꿀 수 있습니다. 공란·중복 이름은 결과 생성을 막습니다. 대소문자나 앞뒤 공백만 다른 이름도 중복으로 표시합니다.
- 참가자를 줄여 비용의 참여자가 없어지면 전체 참여로 바꾸지 않고 재선택을 요청합니다.
- **계산 내역 보기**로 결과의 비용별 합계와 단가 출처를 확인합니다.
- 앱 재실행 후 홈의 이어서 하기로 운행·비용·인원·직접 단가가 보존되는지 확인합니다.

## 기타 지출이 저장된 초안

초안에 통행료 24,000원 / 주차비 8,000원 / 일부 참여 커피 10,001원이 저장돼 있으면 그대로 유지합니다. 기타 지출 추가 메뉴는 없지만 저장된 비용은 접힌 요약에서 합산되고, 펼치면 수정·삭제할 수 있습니다.

초안에 위 비용과 여행 4개 구간이 있으면 총액은 **98,441원**입니다. 4인 부담금은 **27,111 / 27,110 / 22,110 / 22,110원**입니다. 새 정산을 시작하면 이런 추가 비용 없이 기본 차량 비용만 계산합니다.

## 주행 제한

정차 상태에서만 사용합니다. D·30km/h로 전환하면 정산 조작이 차단되고, P·0km/h로 복귀하면 작성 중이던 입력을 이어갑니다. 단가 수정 폼의 저장 전 입력도 보존합니다. 테스트 후 차량 상태는 반드시 P / 0km/h로 돌립니다.
