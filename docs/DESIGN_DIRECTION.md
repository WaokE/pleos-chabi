# 차비 디자인 방향 · 0.6

2026-11-04. 토스·마이루틴·하루콩에서 사용자가 고른 장점을 차량 화면에 맞게 조합했습니다. 각 앱의 브랜드 색·캐릭터·화면을 복제하지 않고, 차비의 독자적인 연두색 자동차와 작은 표정 그래픽을 코드로 그렸습니다.

## 공통 시각 언어

- **색** · 주요 버튼·금액·선택·배경은 Pleos의 그래파이트·팝과 주야간 모드에 맞춰 바뀝니다. OEM 색상이 없으면 주간의 짙은 초록 `#126B58`과 연녹색 `#E4F1E6`, 야간의 밝은 민트 `#A4E2C1`과 어두운 녹색 `#193D32`를 사용합니다.
- **타입**: Pleos의 Asta Sans와 기존 60/56/48·40/36/32·30/28/26·24/20 계층을 유지합니다. 숫자와 중요한 제목은 굵게, 설명은 보조색으로 구분합니다.
- **형태**: 카드 32, 선택 운행 28, 주요 버튼 32의 둥근 모서리. 아이콘은 같은 선 두께의 자체 Canvas 도형으로 통일합니다.
- **캐릭터**: 홈·헤더·결과·런처에서 같은 연두색 자동차를 사용합니다. 참가자 표정은 순서를 구별하는 장식이며 실제 탑승자 정보나 신원을 뜻하지 않습니다.
- **피드백**: 운행 선택 배경은 짧게 전환하며 체크·거리·예상 비용이 동시에 갱신됩니다. 다음 단계는 오른쪽에서, 이전 단계는 왼쪽에서 들어옵니다. 모달과 배경 가림막은 함께 서서히 나타나고 사라집니다.

## 화면별 결정

- **홈**: 큰 제목 “같이 탄 차비, 운행 기록으로 나눠요”와 단일 주요 행동 **운행 고르기**를 중심으로 구성. 저장한 입력이 있으면 **이어서 하기**를 함께 제공. 오른쪽에는 자동차 일러스트와 불러온 운행 기록 요약(개수·날짜 범위·총거리)을 표시합니다. 문구는 [토스 라이팅 원칙](https://toss.tech/article/8-writing-principles-of-toss)에 따라 장식용 슬로건·반복 설명·의미 없는 안내를 두지 않습니다.
- **운행 선택**: 선택 카드와 미선택 카드를 색·테두리·체크로 구별. 넓은 창에서는 오른쪽 지도와 함께 확인하며 하단에 거리·금액·진행 버튼을 고정합니다.
- **비용·인원**: 큰 총액, 적용 기준, 참가 인원, 즉시 바뀌는 1인 부담금 순서. 이름·추가 차량 비용은 필요한 경우에만 펼칩니다.
- **결과**: 1인 부담금과 사람별 금액을 우선 표시하고 예상 총액을 함께 보여줍니다. 1/N 정산은 카카오페이에서 제공하는 Regular 버튼 이미지의 비율을 유지합니다. [카카오페이 디자인 가이드](https://developers.kakaopay.com/docs/moneytransfer/splitbills.link/splitbills-link-hands-on)

## 차량 환경 기준

공식 [Pleos UI 적용 기준](PLEOS_UI_GUIDE.md)을 계속 사용합니다. 버튼은 최소 80, 주요 진행 버튼 100, 텍스트 버튼·선택 칩은 최소 64dp입니다. 넓은 창은 두 열, 좁은 창은 스크롤 가능한 한 열로 전환합니다. 주야간·큰 글꼴·키보드와 주행 제한을 포함한 검증 결과는 [VERIFICATION.md](VERIFICATION.md)에 기록합니다.

## 구현 경계

`app/ui/Design.kt`는 색·타입, `PleosComponents.kt`는 공통 조작 요소, `DriveIllustrations.kt`는 자체 그래픽을 담당합니다. 그림은 운행·차량 데이터 시각화와 분리된 장식입니다. 카드 뽑기의 폭죽은 앱에 포함된 Lottie 벡터 애니메이션으로 재생합니다.
