# 차비 0.6 검증 결과

2026-11-15 기준. 개발 환경은 macOS ARM64와 JDK 17이며, 화면은 Pleos Connect 2.1.0 ARM64(Android API 34) 에뮬레이터에서 확인했습니다.

## 자동 검사

`./scripts/check.sh --offline`으로 아키텍처 경계 검사, 단위 테스트, debug APK 빌드, Android Lint를 통과했습니다.

| 모듈 | 테스트 수 | 확인한 범위 |
| --- | ---: | --- |
| core | 25 | 정수 원 배분, 부분 참여, 단가·연비·전비 검증, 비용 반올림과 초안 편집 규칙 |
| data-local | 2 | 예시 경로 로드의 IO dispatcher 사용, 캐시, 실패 후 재시도 |
| handoff-zxing | 1 | HTTPS 정산 링크 QR 인코딩·판독 후 원문 일치 |
| app | 24 | 운행 선택과 단계 이동, 대체 Repository, 저장과 마지막 단계 복원, 카드 결과 보존·해제, 지도 범위, 주야간 대비 |
| 합계 | **52** | 실패 0 |

개발 APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. GitHub Actions는 같은 검사 스크립트를 사용합니다.

## 에뮬레이터에서 확인한 동작

- 홈에서 운행 선택, 비용·인원 확인, 정산 결과까지 진행하고 날짜별 선택에 따라 지도와 예상 비용이 갱신되는 것을 확인했습니다.
- 결과 화면에서 기본 분담을 확인하고, 카드 뽑기에서 당첨 즉시 나머지 카드가 공개되며 폭죽이 재생되는 것을 확인했습니다. 확정 후에는 당첨자에게 전액이 표시됐습니다.
- 너비를 조정한 카카오페이 버튼으로 QR 모달을 열었습니다. 화면에 표시된 QR을 판독해 앱에 설정한 정산 URL과 일치하는 것을 확인했습니다.
- 지도 왼쪽 아래에 출처와 라이선스 주소가 표시되고, 출처를 눌러도 모달이 열리지 않는 것을 확인했습니다. 확대와 전체 경로 맞춤도 확인했습니다.
