## 에뮬레이터에서 확인한 새 흐름

- 홈 → 새 정산(기존 초안 대체 확인) → 날짜별 4개 Trip 선택 → 415km / 예상 연료비 56,440원.
- 선택을 바꿔도 운행 선택 화면에 머무르며, 하단 확정 버튼으로 비용·인원 화면에 진입.
- 기본 운전자 포함 4명 → 각 14,110원 → 결과와 QR까지 키보드 입력 없이 완료.
- 3명은 18,814 / 18,813 / 18,813원, 5명은 각 11,288원 확인.
- 예시 전기 설정(5km/kWh / 300원/kWh)으로 변경 시 24,900원, 휘발유로 복귀 시 56,440원 확인.
- 소수 단가 1,700.25원/L 적용 시 총 56,448원 / 4명 각 14,112원 확인. Decimal로 계산하며 표시한 단가와 실제 계산 단가가 일치함.
- 가로 앱 창 1682×1210dp, 세로 앱 창 841×1210dp, 야간·시스템 글자 130% 및 키보드 표시 확인.
- 세로 창에서 비용 요약과 인원 선택을 함께 표시하고, 운행 경로도는 펼침 영역으로 제공.
- 키보드 표시 중 적용 버튼에 접근할 수 있고, 폼 취소 시 기존 금액 유지.

- 선택 통행료의 0원 저장 차단, 1,001원 추가 후 57,449원, 삭제 후 56,448원으로 복귀 확인.
- 강제 종료·재실행 후 직접 단가 1700.25와 출처가 유지되고 예상 비용 56,448원으로 재계산됨을 확인.

## QR와 공유

에뮬레이터의 실제 QR 스크린샷을 ZXing 리더로 다시 읽었습니다. 주간 가로 화면의 56,440원 / 14,110원과, 야간·130%·세로 화면의 56,448원 / 14,112원·직접 단가 1700.25가 한글 요약과 함께 정확히 복원됐습니다. 화면에 생성된 QR의 판독까지 확인한 것이며 휴대폰 카메라 실기기 검증을 대신하지 않습니다.

텍스트 QR 지원 리더가 필요합니다. 실제 메신저 전송·송금은 실행하지 않았습니다. 이전 버전에서 확인한 Android 복사/공유 동작을 유지하며, QR은 서버나 네트워크를 사용하지 않습니다.

## 주행 제한

단가 1,800원을 적용 전 입력한 상태에서 D·30km/h로 전환했습니다. 앱의 제한 안내가 노출되고 편집 필드가 제거되는 것을 UI 트리로 확인했으며 이후 Pleos 시스템 주행 차단 화면도 표시됐습니다. P·0km/h 복귀 후 입력 중 폼과 1800 값이 복원됐고, 취소 후 원래 연료비 56,440원을 유지했습니다.

## 0.4 앱 내부 지도 검증 — 2026-11-04

외부 순정 내비 앱 전환 시험 UI·NaviHelper 의존성·관련 권한을 제거하고 목록 오른쪽에 MapLibre + OpenFreeMap 지도를 내장했습니다. 단순 Canvas 경로도도 교체했습니다.

- 추가 지도 테스트 4개: 여러 선택 경로의 전체 범위, 확인 구간 변경과 정산 선택 분리, 선택 없는 경우의 카메라, 누락/손상 좌표의 연결 금지.
- 실제 Pleos 에뮬레이터에서 도로·지명·바다와 선택한 도로 경로의 렌더링 확인. 앱 내부에서 동작하며 외부 내비를 띄우지 않음.
- 날짜별 4개 운행 → 415km / 56,440원, 선택 경로 전체 맞춤, 확대·전체 경로 버튼, 출처 팝업, 비용 화면 진입·지도 복귀 확인.
- 지도 경로 터치 후 확인 구간 제목이 속초→서울로 변경되어도 선택 4개/415km는 유지됨.
- 1682×1210dp 주간/야간 지도와 841×1210dp의 펼침 지도 확인. 스크린샷으로 타일·경로·버튼·출처가 표시되는지 직접 확인함.

## 0.4.1 아키텍처 분리 검증 — 2026-11-04

도메인을 순수 Kotlin `core`, 지도 계약을 `route-map-api`, 현재 SDK 구현을 `route-map-maplibre`로 분리했습니다. Repository/저장 계약은 core로 이동했고 ViewModel의 Mock 기본 생성은 제거했습니다. Application에서 데이터와 지도 구현을 명시적으로 주입합니다. 지도 출처/링크도 구현체 메타데이터를 사용합니다.

- `core:test` 17개 + `app:testDebugUnitTest` 21개 = **총 38개 통과**. 빌드 및 앱/지도 두 모듈 Lint 성공. 앱 Lint 오류 0개/경고 17개(도구·라이브러리·target 권장 16개와 기존 SharedPreferences KTX 권장 1개), 지도 모듈 두 개는 이슈 없음.
- 추가 테스트: 대체 차량 기록/전기 단가 공급자로 753원 정산·배분 일치, 경로 누락/변경 시 정산 금액 불변.
- `verifyArchitecture` 정상 통과. 임시 UI→Mock 참조를 추가했을 때 실패하고, 임시 Gradle init script로 core→지도 API 역참조를 추가했을 때도 실패하는 것을 확인했습니다. 임시 소스는 제거했고 init script는 검증에만 사용했습니다.
- 앱 debugCompileClasspath에 MapLibre/OkHttp 구현 라이브러리가 없는 것을 의존성 보고서에서 확인했습니다. core compileClasspath에는 Kotlin 표준 라이브러리/annotations만 있으며 Android/차량/지도 SDK가 없습니다.

교체 계약/모듈 방향/새 SDK 연결 절차는 [ARCHITECTURE.md](../ARCHITECTURE.md)에 기록했습니다. 실제 Pleos 지도 어댑터는 지원 확인 전이라 추가하지 않았습니다. 과거 운행·GPS 공급과 지도 엔진의 교체는 서로 독립적인 작업입니다.

최종 0.4.1-map-preview APK를 에뮬레이터에 설치해 지도 공급자 주입, 2개 운행/203km/27,608원, 확대·전체 경로, 주입된 출처 팝업, 비용 화면 왕복과 지도 재생성, 주야간 전환을 확인했습니다. D·30km/h에서 지도 UI가 제거되고 P·0km/h 복귀 후 지도와 선택값이 복원됐습니다. 최종 이미지에서 실제 지도 타일/경로 렌더링을 확인했습니다. 네트워크 권한은 앱에 고정하지 않고 지도 구현 모듈 manifest에서 병합되는 것을 확인했습니다.

검증 후 이번 작업 시작 전 초안(선택 운행 0개/추가 비용 0개/참가자 3명)을 복원했고 JSON 전체 일치를 확인했습니다. 앱은 홈, P·0km/h, 주간 모드이며 에뮬레이터는 실행 상태로 유지합니다. 자료는 `.local/architecture-qa/`의 `final-build.txt`, `compile-classpaths.txt`, `forbidden-import.txt`, `forbidden-dependency.txt`, `map-return.png`, `night-injected-map.png`, `driving-gate.png`, `parked-map-restored.png`, `final-home.png`입니다.
